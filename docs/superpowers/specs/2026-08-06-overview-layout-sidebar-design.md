# 平台总览布局与侧边栏调整设计

## 目标

在不改变现有业务数据、摄像头操作、导航点击和页面滚动行为的前提下，调整平台总览模块顺序，完善暗色主题，并重组侧边栏账号区域。

## 页面布局

- 将完整“平台汇总”模块（汇总指标、全部摄像头列表及新增、修改、删除操作）移动到当前“统一监管总览”所在的上方主区域。
- 将当前“统一监管总览”移动到原“平台汇总”所在的右侧区域，并改名为“监管概况”。
- 保持“最近异常”和“运行状态看板”的现有相对位置及功能不变。
- 移除平台总览主要内容卡片与功能入口卡顶部的彩色渐变条；保留状态本身需要的徽标、图标和告警颜色。

## 暗色主题

- 为“监管概况”及其四个指标子卡补齐暗色背景、边框、数值、图标、标题与说明文字样式。
- 暗色主题仍由现有 `dark` class 机制控制，不新增状态或依赖。

## 导航与账号操作

- 删除侧边栏顶部吉祥物头像，仅保留“福达视觉平台”和“AI Vision Platform”。
- 删除侧边栏底部“系统正常/部分异常/模块离线”全局状态卡。
- 将顶部栏中的工号、姓名、角色、修改密码和退出操作迁移到侧边栏底部。
- 修改密码弹窗及表单逻辑随账号操作一起迁入侧边栏，继续复用现有鉴权上下文。
- 侧边栏折叠时以图标按钮呈现账号操作；移动端保持可点击且不遮挡导航。
- 顶部栏仅保留侧边栏切换、页面标题和主题切换按钮。

## 组件边界

- `HomeSection.tsx` 负责平台总览内容换位、标题和主题样式。
- `Sidebar.tsx` 负责品牌区、账号信息与账号操作。
- `Topbar.tsx` 移除已迁移的账号状态和弹窗逻辑。
- 不新增依赖，不改后端接口，不重构无关代码。

## 验证

- 使用现有前端测试验证平台总览关键结构与文案。
- 执行 TypeScript/Vite 构建，确认组件类型和 Tailwind 类名编译成功。
- 静态核对顶部栏不再含账号操作、侧边栏不再含头像和全局状态卡、平台总览不再含顶部彩条。

## 风险控制

- 模块换位仅调整 JSX 区块，不复制摄像头状态和事件处理，避免产生两套行为。
- 修改密码状态只保留一份，迁移后从顶部栏彻底删除，避免重复弹窗。
- 保留侧边栏滚动区域与底部区域的 flex 布局，避免账号操作影响导航滚动。
