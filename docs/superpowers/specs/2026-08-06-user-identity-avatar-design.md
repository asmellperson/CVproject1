# 文字头像与用户信息展示设计

## 目标

在平台顶栏和侧边栏底部统一展示当前登录用户信息。使用文字头像替代图片，不改变登录、当前用户、修改密码或退出接口。

## 组件设计

新增可复用的 `UserIdentity` 展示组件，接收现有 `AuthUser`：

- 头像为约 36px 的圆形 `div`，使用青色到靛蓝色渐变、白色文字和水平垂直居中布局。
- 头像文字直接由 `user.name.slice(-1)` 得到，不写死姓名；姓名为空时显示空字符串，避免展示错误身份信息。
- 用户信息展示姓名、角色徽章和工号。角色使用现有 `user.role`，视觉上保持大写；工号使用现有 `user.employee_id`。
- 支持横向紧凑布局，供顶栏和侧边栏底部复用。组件只负责展示，不负责请求、认证或操作按钮。

## 接入方式

- `Topbar` 继续通过 `useAuth()` 读取当前用户，在主题按钮前显示用户信息。小屏空间不足时保留头像，并隐藏详细文字，避免挤压页面标题和操作按钮。
- `Sidebar` 底部使用同一组件替换当前手写的工号、姓名和角色区域；修改密码和退出按钮保持原有行为。
- 侧边栏折叠状态保持现有操作布局，不额外改变导航、滚动或点击逻辑。

## 数据流与接口

数据继续来自 `AuthProvider` 已有的 `/api/auth/login` 和 `/api/auth/me` 响应，并由 `useAuth()` 提供。此次不修改接口路径、返回结构、类型或状态管理。

## 范围外事项
