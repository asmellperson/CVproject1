# 会话内设计与 Skill 最小化规则设计

## 目标

在项目根目录 `AGENTS.md` 中明确：项目设计和实施计划默认只在当前会话中向用户说明，不创建或提交设计、规格、计划类 Markdown 文件；同时禁止主动读取或启动 skill 流程。

## 规则

- 设计方案、需求澄清、实现计划和任务拆分默认直接在会话中给出。
- 不创建或提交 `docs/superpowers/specs/`、`docs/superpowers/plans/`，也不为流程性文档单独创建 Git 提交。
- 只有用户明确要求保存文档，或系统、开发者等更高优先级指令明确强制要求时，才能创建上述文档。
- 不主动读取 `/root/.agents/skills` 或其他 skill 文件，不主动启动 skill 工作流。
- 系统或开发者明确强制使用 skill 时，必须遵守更高优先级要求，但要在执行前向用户说明原因，并将流程控制在完成强制要求所需的最小范围内。
- 不得向用户承诺能够通过项目 `AGENTS.md` 禁用系统或开发者强制要求。

## 边界

- 本规则只影响当前项目。
- 本次修改仅涉及协作说明文档，因此不更新远程 `V4`。
- 当前规格文档由本次会话已经生效的高优先级 brainstorming 流程强制创建；新规则生效后，在没有更高优先级要求时不再创建同类文档。
