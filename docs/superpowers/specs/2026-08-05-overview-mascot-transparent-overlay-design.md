# 平台总览吉祥物透明悬浮动画设计

## 目标

把 `unified_frontend/public/平台总览动画.mp4` 中的吉祥物作为平台总览横幅内的透明覆盖层。标题“福达 AI 视觉安全监管平台”以整个横幅为基准居中并始终保持单行，不能因为吉祥物而右移。

## 媒体处理

- 从原视频逐帧生成前景遮罩，保留吉祥物主体，去除浅色背景、左右黑边、地面、阴影和右下角标记。
- 对遮罩做连通域筛选与边缘羽化，避免把地面阴影或孤立水印带入成品，同时保留角色内部的白色护甲与透明面罩高光。
- 输出带 Alpha 通道的 VP9 WebM，静音且不携带原音轨。
- 从最后的趴姿帧输出透明 PNG，作为播放结束后的确定性停留画面、视频加载失败兜底和移动端静态资源。
- 输出资源统一放在 `public/assets/overview/`，不增加第三方依赖。

## 页面结构与交互

- 横幅背景图、渐变遮罩和既有内容结构保持不变。
- 新增一个绝对定位的吉祥物按钮层：左侧对齐、高度始终与横幅一致，宽度按透明素材 `600:544` 的比例自动计算，整体透明度 50%。
- 标题容器保持横幅居中，标题使用 `white-space: nowrap` 与响应式字号保证单行；不为吉祥物添加左侧内容留白。
- `<video>` 首次挂载时自动播放一次，不设置 `loop` 或播放器控件。
- 播放结束后隐藏视频并展示透明趴姿 PNG；点击吉祥物时将视频归零、显示视频并重新播放一次。
- 吉祥物容器以外保持 `pointer-events: none`，只有按钮自身响应点击，不影响横幅、页面滚动或其他操作。
- 小于 768px 时不播放动画，只显示与横幅等高、按素材比例自动计算宽度的透明趴姿 PNG。

## 组件边界

把媒体播放状态和重播逻辑收敛到独立的 `OverviewMascot` 组件，`HomeSection` 只负责把组件放入横幅。这样不会继续扩大已有的首页业务组件，也便于单独测试播放行为和响应式样式。

## 验证

- 契约测试验证 WebM、透明 PNG、无循环、点击重播、结束切换静态图、横幅等高与素材宽高比规则、标题居中单行。
- `ffprobe` 验证 WebM 为 VP9 且带 `alpha_mode=1`，无音频流。
- 对首帧、中间帧、末帧生成透明背景接触表，检查黑边、背景、地面、阴影和水印已经移除。
- 运行前端测试、TypeScript/Vite 构建，并在桌面与小于 768px 的视口检查横幅布局。

## 风险与边界

- 原素材不是绿幕且包含浅色角色部件，单纯色键会误删角色，因此使用主体遮罩与连通域筛选；细小透明面罩反光可能需要轻微羽化取舍。
- 浏览器对自动播放的限制通过 `muted`、`playsInline` 处理；若仍失败，页面直接显示趴姿 PNG，不出现矩形播放器。
