# 删除平台总览底部功能入口设计

## 目标

删除平台总览页面最底部按事业部分组展示、带“进入功能”按钮的功能入口卡片区域，使页面在监管概况模块后结束。

## 修改范围

- 从 `HomeSection` 的渲染结构中删除管理员分组入口卡片和普通用户入口卡片。
- 删除仅供该区域使用的 `ModuleEntryCard` 组件、类型和图标导入。
- 保留 `moduleEntries` 数据及权限过滤，因为页面上方模块状态、模块覆盖和运行状态计算仍依赖这些数据。

## 不变行为

- 左侧导航入口和所有功能页面保持不变。
- 平台汇总、监管概况、摄像头管理、最近异常和运行状态看板保持不变。
- 用户权限、接口请求和 `onNavigate` 的其他用途保持不变。

## 验证

- 添加契约断言，确认平台总览不再渲染 `ModuleEntryCard` 或“进入功能”。
- 运行全部前端契约测试、生产构建和 lint。
