# 导航栏一级目录字号调整设计

## 目标

放大侧边栏中以下六个一级目录的字号，使其与下方检测能力名称形成清晰的视觉层级：

- 通用电气事业部
- 电子电工事业部
- 电气部件事业部
- 贵金属回收事业部
- 研究院
- 公共能力

## 现状

六个一级目录由 `unified_frontend/src/components/Sidebar.tsx` 中同一个按钮样式渲染，当前字号为 `text-base`（16px）。下方检测能力名称字号为 15px，两者仅相差 1px，层级区分不明显。

## 设计

将一级目录按钮的字号类从 `text-base` 调整为 `text-lg`（18px）。保留现有粗体、颜色、间距、折叠和展开行为；二级检测能力名称仍为 15px。

本次只修改六个一级目录共用的样式，不修改目录文字、权限过滤、菜单数据、二级菜单样式或其他导航项。

## 验证

1. 执行统一前端现有的静态检查或构建命令。
2. 检查构建无 TypeScript 或 Tailwind 类名错误。
3. 人工确认六个一级目录均显示为 18px，二级检测能力名称仍为 15px，展开与收起行为不变。

## 风险

风险较低。较长的“贵金属回收事业部”仍使用现有单行截断策略；侧边栏宽度不变，极窄视口下可能比原字号更早触发截断。
