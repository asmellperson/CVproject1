# 前端夜间模式全量适配设计

## 目标

统一补齐前端各页面的夜间模式，解决保安行为规范检测、安检流程规范数据汇总及其他检测模块在夜间模式下仍显示浅色背景、深色文字或浅色边框的问题。

本次只调整前端主题初始化和展示样式，不修改后端代码、接口请求、数据字段、摄像头视频播放、ROI 坐标、检测逻辑或告警逻辑。

## 主题行为

- 浏览器没有保存过主题选择时，默认启用夜间模式；
- 用户点击右上角主题按钮后，将 `light` 或 `dark` 写入现有 `unified-frontend-theme` 存储项；
- 刷新页面或下次打开时继续使用用户上一次选择；
- `index.html` 的首屏脚本和 React `useTheme` 使用完全相同的默认逻辑，避免页面加载时先亮后暗；
- 不跟随操作系统主题自动变化，未保存选择时固定为夜间模式。

## 适配策略

采用“全局主题基础能力 + 页面明确夜间样式”的方式：

1. 保留现有 CSS 变量和通用深色兼容规则，补充遗漏的固定页面背景色处理；
2. 对页面容器、卡片、标题、说明文字、边框、输入控件、标签页和空状态增加明确的 `dark:` 样式；
3. 优先修改共用视图，使复用该视图的多个检测页面一次完成适配；
4. 保持 emerald、amber、rose、cyan 等业务状态颜色的语义，不对视频帧、ROI、警戒线和告警覆盖层做颜色反转；
5. 不依赖只针对某个 Tailwind 类名的全局强制覆盖来掩盖页面问题。

## 页面范围

### 保安行为规范检测

- 页面标题、副标题和实时监控/配置管理分段控件；
- 四张统计卡；
- 监控对象、检测控制、实时检测项、检测详情和最近报警；
- 配置管理中的站点、摄像头和配置卡片。

### 安检流程规范

- 页面标题和主级分段控件；
- 运行状态与操作按钮；
- 安检检测概览和顶部数据汇总；
- 视频区域、历史记录；
- 摄像头管理和 ROI 绘制配置区域。

### 检测模块

- 区域入侵、人脸检测、手机识别和大门开关共用仪表盘；
- 人员逗留检测；
- 物流通道单人检测及三个部门复用页面；
- 各检测页面外层标题区、分段控件和配置管理内容。

### 其他可访问页面

检查并补齐告警记录、统计分析、用户管理以及仍在路由中的通用监控/配置组件。平台总览已经有较完整的夜间样式，仅修复审计中确认的遗漏，不重做布局。

## 组件边界

- `index.html` 和 `use-theme.ts` 只负责主题初始值、应用和持久化；
- 页面 Section 只负责页面外层和本页独有模块的颜色；
- `GuardMonitorUi`、`FeatureDashboardMonitorView`、`HumanDwellMonitorView`、`LogisticsSinglePersonMonitorView` 等共用展示组件负责其内部卡片和文字；
- UI 基础组件继续使用现有语义化 CSS 变量，不新增依赖或第二套主题系统。

## 视觉规则

- 夜间页面背景使用 `slate-950` 或现有 `background` 变量；
- 夜间卡片使用 `slate-900`，边框使用 `slate-800`；
- 主标题使用 `slate-100`，正文使用 `slate-300`，辅助文字使用 `slate-400`；
- 输入框和未选中分段控件使用 `slate-900/80`、`slate-800`；
- 选中态继续使用平台深蓝的夜间可读变体，不改变功能状态色；
- 视频容器维持黑色背景，所有覆盖层继续 `pointer-events-none`。

## 错误和兼容处理

- `localStorage` 中只有 `light` 和 `dark` 被视为有效值，其他值按首次访问处理并默认夜间；
- 主题脚本继续在 React 加载前执行，防止闪烁；
- 不清除已有用户选择，不强制已经选择白天模式的用户切回夜间；
- 小屏布局、滚动和点击行为保持不变。

## 验证

- 新增主题契约测试，验证 HTML 首屏脚本与 Hook 均以夜间作为无存储值时的默认值；
- 验证手动选择仍写入并读取同一个存储项；
- 对目标 Section 和共用视图检查关键页面容器、卡片、标题、边框与输入控件存在夜间样式；
- 运行全部前端测试、TypeScript/Vite 生产构建、ESLint 和 `git diff --check`；
- 检查差异中没有后端路径、接口调用或检测逻辑改动；
- 不启动开发或预览服务器，不创建测试网页，不占用端口。

## 不在范围内

- 不重新设计页面布局；
- 不改变主题切换按钮的位置和图标逻辑；
- 不新增主题依赖；
- 不修改后端、数据库、模型或检测服务；
- 不推送远程或移动 V4 标签，除非用户另行要求。
