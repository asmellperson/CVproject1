# 四类检测页面统一监控仪表盘设计

## 目标与范围

将研究院下的区域入侵检测、人脸检测、手机识别检测，以及公共能力下的大门开关检测，重构为与人员逗留检测一致的前端监控仪表盘。

本次只调整前端实时监控区域的布局和展示样式。现有接口路径、请求参数、字段绑定、JPEG 视频帧轮询、ROI/警戒线坐标、检测逻辑、告警逻辑和全部后端代码保持不变。

## 统一视觉规范

- 页面主色为 `#132C72`，背景为 `#F3F5FA`；
- 卡片使用白色背景、`rounded-2xl`、浅色边框和轻阴影；
- 页面顶部为左侧标题与副标题、右侧圆角“实时监控 / 配置管理”分段控件；
- 实时监控依次展示四张统计卡，以及左一列、右两列的三列主体布局；
- 左列固定为“监控对象 / 判定说明 / 最近报警”；
- 右侧为业务视频卡，包含标题、副标题、FPS、LIVE、玻璃状态胶囊、轻微暗角和左下时间戳；
- ROI 使用青色描边和浅青填充；区域入侵继续保留原有红色警戒线位置、形状及坐标。

## 页面业务内容

### 区域入侵检测

- 标题：区域入侵检测监控与配置；
- 副标题：警戒区域实时监控面板；
- 统计卡：摄像头状态、启用摄像头、警戒方向、今日入侵告警；
- 判定说明：警戒线、入侵侧和当前检测阈值；
- 视频状态胶囊：实时检测、摄像头在线状态、警戒线配置状态。

### 人脸检测

- 标题：人脸检测监控与配置；
- 副标题：人脸识别实时监控面板；
- 统计卡：摄像头状态、启用摄像头、人脸置信度阈值、今日人脸告警；
- 判定说明：检测 ROI、置信度阈值和角度阈值；
- 视频状态胶囊：实时检测、摄像头在线状态、人脸检测状态。

### 手机识别检测

- 标题：手机识别检测监控与配置；
- 副标题：手机使用识别监控面板；
- 统计卡：摄像头状态、启用摄像头、确认持续时间、今日手机告警；
- 判定说明：检测 ROI、手机置信度和人体关联配置；
- 视频状态胶囊：实时检测、摄像头在线状态、手机识别状态。

### 大门开关检测

- 标题：大门开关检测监控与配置；
- 副标题：大门状态异常监控面板；
- 统计卡：摄像头状态、启用摄像头、首次告警时间、今日大门告警；
- 判定说明：检测 ROI、变化阈值和首次告警时间；
- 视频状态胶囊：实时检测、摄像头在线状态、大门状态检测。

## 数据来源与统计口径

所有数据只来自现有前端可用接口：

- 摄像头状态取当前 JPEG 画面是否成功连接；
- 启用摄像头数量取当前功能过滤后的现有摄像头列表长度；
- 页面专属配置值取 `AiVisionMonitor` 已读取的现有功能配置：
  - 区域入侵使用 `alarm_side`；
  - 人脸检测使用 `FACE_SCORE_THR`；
  - 手机识别使用 `MIN_CONFIRM_SECONDS`；
  - 大门开关使用 `first_alarm`；
- 今日告警和最近报警继续调用现有 `getAlarms`，事件类型分别为 `blocks`、`detect_face`、`detect_phone`、`detect_door`；
- 告警只统计当前选中摄像头和本地当天；最近报警最多展示 5 条。

不新增状态接口，不推测画面人数、目标数量或当前异常状态，不把配置值包装成实时检测结果。

## 组件边界

### `AiVisionMonitor`

继续负责以下现有生命周期：

- 摄像头列表与当前摄像头选择；
- 功能配置读取；
- JPEG 视频帧请求与 200ms 串行刷新；
- 请求超时和取消；
- Blob URL 创建与回收；
- 页面可见性处理；
- 帧原始尺寸与覆盖层坐标空间。

增加统一业务仪表盘展示模式，把现有摄像头、视频帧、配置值、覆盖层和回调传给新视图。默认展示模式、物流单人检测和人员逗留检测不受影响。

### 通用检测仪表盘视图

新增一个纯展示组件，通过功能配置描述决定标题、业务统计卡、判定说明、状态胶囊和覆盖层标签。四个页面复用同一布局，避免复制四套大型 JSX。

该组件不发请求、不保存业务状态，也不修改配置。

### 通用报警 Hook

新增前端 Hook，复用现有 `getAlarms`：

- 每 5 秒使用递归 `setTimeout` 串行轮询；
- 按功能事件类型、当前摄像头和本地日期过滤；
- 请求失败时保留上一次成功结果；
- 切换摄像头时立即清空旧报警，防止数据串台；
- 返回今日告警数量和最近 5 条报警。

### 四个 Section 页面

四个页面只调整：

- 外层页面背景和间距；
- 页面标题与副标题；
- 主级分段控件样式；
- `AiVisionMonitor` 的展示模式参数。

配置管理下的摄像头管理、参数配置、ROI/警戒线绘制、模型配置、报警推送以及全部处理函数保持原样。

## 删除、替换与新增

### 替换的旧展示

- 实时监控区旧通用卡片头；
- 旧卡片头中的横向摄像头选择和刷新区域；
- 旧的单独“实时检测”悬浮标签样式；
- 四页实时监控区不统一的卡片背景。

这些展示会由新仪表盘中的“监控对象”卡、业务视频卡和状态胶囊替代。摄像头选择及刷新行为本身不会删除。

### 新增模块

- 页面标题、副标题和圆角分段控件；
- 每页四张现有数据统计卡；
- 左侧“监控对象 / 判定说明 / 最近报警”；
- 新业务视频卡头和状态覆盖层；
- 共用的检测仪表盘视图、功能展示配置和报警 Hook；
- 前端布局与数据口径契约测试。

### 完整保留

- 配置管理的五个子页面；
- 摄像头增删改选、刷新和配置复制；
- 参数表单、日夜预设、读取和保存；
- ROI/警戒线绘制及坐标；
- 模型配置和报警推送；
- 管理员与查看者权限判断；
- 全部现有接口、视频和检测逻辑。

## 错误与空状态

- 无摄像头时保留现有引导文案；
- 视频帧读取失败时显示离线和现有错误信息；
- 配置值缺失时业务统计显示 `--`；
- 报警请求失败时保留最近一次成功列表；
- 当前摄像头无今日报警时显示“今日暂无报警”；
- 覆盖层全部使用 `pointer-events-none`，不得影响页面点击和滚动。

## 验证方案

- 新增前端契约测试，覆盖四个页面标题、展示模式和配置管理绑定仍然存在；
- 覆盖通用视图的统计卡、三列布局、视频状态胶囊、ROI/警戒线分支和最近报警；
- 覆盖报警过滤的事件类型、当前摄像头、本地日期、最多 5 条、切换清空和串行轮询；
- 确认 `AiVisionMonitor` 的帧 URL、刷新周期、请求取消、Blob 回收和原始尺寸读取没有改变；
- 运行全部前端契约测试、生产构建、lint 和 `git diff --check`；
- 不启动项目预览服务，不遗留测试网页或端口。

## 不在本次范围内

- 不修改任何后端文件；
- 不新增或扩展后端接口；
- 不修改检测、推理、跟踪、告警或入库逻辑；
- 不调整配置字段含义和默认值；
- 不伪造后端未提供的实时检测数据；
- 不重构与四个目标页面无关的功能。
