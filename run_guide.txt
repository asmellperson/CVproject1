推荐：统一管理五个服务
========================================
以下命令都在项目根目录执行：

cd /srv/Fuda_CVPreject

# 启动五个服务（已有同名 tmux 会话时会跳过，不影响正在运行的服务）
bash scripts/start.sh

# 统一后端会自动优先使用名为 unified_backend 的 Conda 环境。
# 目标服务器已有该环境时无需修改任何项目配置文件。

# 查看五个服务的 tmux、端口和健康状态
bash scripts/status.sh

# 停止五个服务（执行时需要输入 yes 确认）
bash scripts/stop.sh

# 停止五个服务且不再询问
bash scripts/stop.sh -y

# 强制重启五个服务
bash scripts/start.sh --force

统一启动后会创建以下五个 tmux 会话：
- unified_frontend：前端，端口 3000
- unified_backend：统一后端，端口 5000
- guard_room：保安行为规范检测，端口 5001
- aivision：AiVision，端口 7862
- security_vlm：安全生产 VLM，端口 8000

首次启动时，如果 scripts/auth_secret 不存在，脚本会提示输入 yes 后生成。
后续启动会继续复用该文件，并把同一个 AUTH_SECRET 注入
unified_backend、guard_room 和 aivision，避免点击子系统后登录失效。
不要分别为这三个后端配置不同的 AUTH_SECRET。

退出窗口（启动了窗口后要按这个退出窗口）

Ctrl + B
松开
再按 D

以下为单独启动某个服务的排障备用方式，正常运行优先使用 scripts/start.sh。

1、启动unified_frontend:
tmux new -s unified_frontend
cd unified_frontend
npm run dev
如需临时改端口：npm run dev -- --port <前端调试端口>

2、启动unified_backend（统一后端，固定对外 5000）:
tmux new -s unified_backend
conda activate unified_backend
export AUTH_SECRET="<所有后端保持同一串32位以上随机密钥>"
python -m unified_backend.run_server
如需临时改端口：python -m unified_backend.run_server --port <统一后端调试端口>

3、启动guard_room（内部服务，默认 5001）:
tmux new -s guard_room
conda activate guard_room (保安行为规范检测使用的是guard_room的conda环境)
cd guard_room
export AUTH_SECRET="<所有后端保持同一串32位以上随机密钥>"
python run_server.py --host 127.0.0.1 --port 5001
如需临时改端口：python run_server.py --port <guard_room调试端口>

4、启动AiVision（内部服务，默认 7862）
tmux new -s aivision
conda activate aivision (AiVision使用的是aivision的conda环境，python 3.11)
cd AiVision
export AUTH_SECRET="<所有后端保持同一串32位以上随机密钥>"
python main.py --host 127.0.0.1 --port 7862
如需临时改端口：python main.py --port <AiVision调试端口>

5、启动security_vlm:
tmux new -s security_vlm
cd security_vlm
conda activate security_vlm1
python src/main.py --config configs/config.yaml --host 127.0.0.1 --port 8000
如需临时改端口：python src/main.py --config configs/config.yaml --port <security_vlm调试端口>


6、tmux常用命令:
查看所有正在跑的tmux：
tmux ls



python AiVision/main.py --port <端口>
python security_vlm/src/main.py --config configs/config.yaml --port <端口>
npm run dev -- --port <端口>

如何添加新工号

  编辑：

  /usr/zyy/Fuda_CVPreject_V3/auth/auth_users.json

  追加：

  {
    "employee_id": "10003",
    "name": "新用户",
    "role": "viewer",
    "enabled": true

  AUTH_DEFAULT_PASSWORD='新密码'

  如何区分 admin 和 viewer

  在 auth_users.json 里改 role：

  "role": "admin"

  或：

  "role": "viewer"

  admin 可修改配置、启停算法、录屏；viewer 只能查看。
