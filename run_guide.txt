使用tmux在后端跑代码：下载：
apt update
apt install -y tmux

退出窗口（启动了窗口后要按这个退出窗口）
################
Ctrl + B
松开
再按 D
###############
进入已有窗口：
****************************************
tmux attach -t unified_frontend
tmux attach -t unified_backend
tmux attach -t guard_room
tmux attach -t aivision
tmux attach -t security_vlm
****************************************
关闭程序：
****************************************
tmux kill-session -t unified_frontend
tmux kill-session -t unified_backend
tmux kill-session -t guard_room
tmux kill-session -t aivision
tmux kill-session -t security_vlm
****************************************

1、启动unified_frontend:
tmux new -s unified_frontend
cd unified_frontend
npm run dev
如需临时改端口：npm run dev -- --port <前端调试端口>

2、启动unified_backend（统一后端，固定对外 5000）:
tmux new -s unified_backend
export AUTH_SECRET="<所有后端保持同一串32位以上随机密钥>"
python -m unified_backend.run_server
如需临时改端口：python -m unified_backend.run_server --port <统一后端调试端口>

3、启动guard_room（内部服务，默认 5001）:
tmux new -s guard_room
conda activate guard_room (保安行为规范检测使用的是guard_room的conda环境)
cd guard_room
export AUTH_SECRET="<所有后端保持同一串32位以上随机密钥>"
python run_server.py --host 127.0.0.1 --port 5001
如需临时改端口：python run_server.py --port <guard_room调试端口>

4、启动AiVision
tmux new -s aivision
cd AiVision
export AUTH_SECRET="<所有后端保持同一串32位以上随机密钥>"
uv run main.py --host 127.0.0.1 --port 7862
如需临时改端口：uv run main.py --port <AiVision调试端口>

5、启动security_vlm:
tmux new -s security_vlm
cd security_vlm
conda activate security_vlm1
python src/main.py --config configs/config.yaml --host 127.0.0.1 --port 8000
如需临时改端口：python src/main.py --config configs/config.yaml --port <security_vlm调试端口>


6、tmux常用命令:
查看所有正在跑的tmux：
tmux ls

python security_vlm/src/main.py --config configs/config.yaml --port <端口>

如何添加新工号

  编辑：

  /usr/zyy/Fuda_CVPreject_V3/auth/auth_users.json

  追加：

  {
    "employee_id": "10003",
    "name": "新用户",
    "role": "viewer",
    "enabled": true

  AUTH_DEFAULT_PASSWORD='新密码'

  如何区分 admin 和 viewer

  在 auth_users.json 里改 role：

  "role": "admin"

  或：

  "role": "viewer"

  admin 可修改配置、启停算法、录屏；viewer 只能查看。
